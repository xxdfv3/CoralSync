# Figma First Draft — Design Prompt for CoralSync

Use this prompt in Figma First Draft (in English) to generate a UI mockup. Describe everything in text; avoid relying on links.

---

## Prompt (copy below)

**Project:** CoralSync — a web app for tracking anime, movies, and TV shows (similar to MyAnimeList and Letterboxd). Users have watchlists, rate titles, log progress (episodes watched), write reviews, and see activity. The name suggests “coral” (warm, organic, underwater) and “sync” (keeping everything in one place). You may use subtle coral/teal/ocean accents or a clean neutral palette; avoid a literal underwater theme — keep it modern and minimal.

**Design reference (describe this style):**  
Create a clean, modern dashboard layout with plenty of white space, rounded corners, and soft shadows. Three main areas:

1. **Left sidebar (fixed):**  
   Main navigation: Overview (or Home), My List, Discover (or Browse), Schedule, Search. Secondary: Notifications (with optional unread badge), Settings. Bottom: user block with avatar and label (e.g. “Member” or username). Use clear hierarchy and short labels.

2. **Top header:**  
   Breadcrumbs on the left (e.g. “CoralSync > My List > Watching”). Right side: global search icon, notification bell, user avatar. Keep it minimal and uncluttered.

3. **Main content area:**  
   Split into a primary column and an optional right column.

   - **Primary (left):**  
     **“Activity” or “Activity feed”** — timeline of the user’s recent actions. Each row = one day. Show chips/cards per action with: icon, short label, and time. Examples: “Watched episode 5 of [Title]”, “Rated [Title] 4 stars”, “Added [Title] to watchlist”, “Updated progress”. Use soft accent colors (e.g. blue for “watched”, green for “rated”, coral/teal for “added”) and small icons so activity types are scannable. Above the timeline: title “Activity” and a “Filter” button (optional badge “1” if a filter is active). Month navigation with tabs (e.g. Jan, Feb, Mar) and arrows to switch months.

   - **Right column (optional):**  
     - **Mini calendar:**  
       One month view; current day clearly highlighted (e.g. dark circle). Optional legend: “Watched 6”, “Rated 2”, “Events 8” or similar counts.  
     - **“Upcoming” or “Upcoming releases”:**  
       List of cards. Each card: title (e.g. “New episode — [Show Name]”), date and time (e.g. “12 Feb — 7:30”), and “X days left” or “In 2 days”. Use subtle background colors per card type (e.g. new episode, new season, friend activity). Include a “Filter” button. This block is inspired by “new episodes” and “schedule” sections on anime catalog sites: focus on what’s coming next for the user.

**Visual style:**  
- Typography: clean sans-serif, clear hierarchy (one strong heading, readable body, small labels).  
- Colors: light gray and white backgrounds; dark gray or black text; accent colors for activity types and CTAs (coral/teal if you use the brand; otherwise blue/green/orange).  
- Components: rounded rectangles for cards and chips, light borders or shadows, no heavy decoration.  
- Layout: responsive-friendly — sidebar can collapse to icons on smaller screens; main area stacks or stays full-width.

**Reference vibe (Anilibria-style, described in text):**  
Think of a typical anime/catalog site: emphasis on “new episodes” and “recent updates”, a clear schedule or calendar, and easy browsing of titles. Use a clear content hierarchy: primary = user’s own activity and lists; secondary = discovery and upcoming. Avoid visual noise: no heavy gradients or gaming-style UI. Prefer a calm, content-first layout similar to a well-organized tracking or catalog dashboard.

**Deliverables:**  
- One main dashboard screen showing: sidebar + header + activity timeline + right column (calendar + upcoming).  
- Optional: a second frame with the same layout but “My List” or “Discover” as the main content (e.g. grid of title cards with poster, title, progress) so the navigation and structure are consistent.

## Short version (if character limit is tight)

**CoralSync** — anime/movie/TV tracking app (like MyAnimeList/Letterboxd). Design a clean dashboard: fixed left sidebar (Home, My List, Discover, Schedule, Settings, user); top bar with breadcrumbs, search, notifications, avatar; main area = “Activity” timeline (chips with icon + label + time per action: watched, rated, added to list); right column = mini calendar + “Upcoming releases” cards (title, date, “X days left”). Use soft accents (coral/teal optional), rounded corners, light shadows, sans-serif. Content-first, minimal, no gaming aesthetic. Optional second frame: same layout with “My List” as grid of title cards.
