# Логотип CoralSync

## Куда положить файл

Положите ваш SVG-логотип в корень папки **`public/`** с именем:

- **`public/logo.svg`**

Тогда он будет доступен по адресу `/logo.svg` и автоматически подхватится в интерфейсе.

## Где используется

- **Главная страница** (`HomePage`) — логотип по центру/сверху, по клику ведёт на `/`.
- Компонент **`@/shared/ui/logo`** — можно использовать в шапке, в формах входа/регистрации и в любом другом месте.

## Иконка вкладки браузера (favicon)

Чтобы логотип отображался во вкладке браузера:

1. Скопируйте ваш SVG в **`app/icon.svg`** (или переименуйте/адаптируйте под квадратную иконку).
2. Next.js автоматически использует `app/icon.svg` как favicon.

Если логотип широкий, можно сделать отдельный упрощённый вариант только для `app/icon.svg`.

## Имя файла

Если вы назовёте файл иначе (например `coralsync-logo.svg`), измените константу `LOGO_PATH` в `src/shared/ui/logo.tsx` на `'/coralsync-logo.svg'`.
